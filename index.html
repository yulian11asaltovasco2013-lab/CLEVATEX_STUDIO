Preguntas frecuentes

Algunas preguntas que puedes tener antes de solicitar un proyecto.

¿Cuánto cuesta un proyecto? +

Tenemos servicios desde $30.000 COP. Los proyectos personalizados pueden tener un precio diferente dependiendo de las funciones necesarias.

¿Puedo pedir algo que no esté en los servicios? +

Sí. Puedes solicitar un proyecto personalizado y explicar qué necesitas. Primero revisamos la idea y definimos las funciones.

¿Las páginas funcionan en celular? +

Sí. Las páginas se pueden diseñar para adaptarse a diferentes tamaños de pantalla, especialmente celulares.

¿Cómo solicito un proyecto? +

Puedes utilizar el formulario de esta página. Al enviarlo se abrirá WhatsApp con la información de tu solicitud.

¿El precio puede cambiar? +

Sí. Antes de comenzar se revisan las necesidades del proyecto y se confirma el precio correspondiente.

Condiciones de trabajo

Para que el proceso sea claro desde el comienzo.

🔒 Claridad

Antes de comenzar se define qué incluye el proyecto, sus funciones principales y el precio acordado.

🛠️ Desarrollo

El proyecto se desarrolla de acuerdo con las características y necesidades previamente establecidas.

💬 Comunicación

Los cambios importantes o nuevas funciones pueden requerir una nueva revisión del proyecto y del precio.
